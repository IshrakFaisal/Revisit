Revisit

For a post in a feed, right-click its timestamp or permalink and choose Save link to Revisit. Confirm the draft and save it in the app.

Keep Revisit running to receive context arrivals. Closing it stops delivery; arrivals are not queued.

On X or Facebook, Revisit can offer to add a post after you use the site's Bookmark or Save post button. Refresh the page after granting access. If the prompt doesn't appear, use the explicit Save action or permalink menu.

Automatic detection sends only X/Facebook/GitHub context and event IDs/timing. It requires site access. Saved URLs are not retained by the extension.
